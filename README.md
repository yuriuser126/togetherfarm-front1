## 📌 오늘 진행 내용
- React + Next.js 기반 **스플래시 페이지 초기 구현**
- **Radix UI 컴포넌트** 활용: HoverCard, Table, Switch 등
- 디자인팀 화면이 아직 진행 중이라, 임시 구성으로 프론트엔드 팀과 **코드 리뷰 진행**
- Git 브랜치 전략 활용: 메인 브랜치와 별도 브랜치로 나누어 **개인 레포에서 작업**
- 멘토링 전까지 **기본 기능과 구조 완성 목표**
